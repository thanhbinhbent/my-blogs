This lesson covers health probes:

- **Liveness probe**: container is alive; fail → restart
- **Readiness probe**: container is ready for traffic; fail → remove from Service endpoints
- **Startup probe**: container has finished initializing; blocks liveness checks until success
- Probe types: HTTP GET, TCP Socket, gRPC, Exec command
- Probe parameters: `initialDelaySeconds`, `periodSeconds`, `failureThreshold`, `successThreshold`
- Common mistakes: overly strict probes causing restart loops
- Designing good health check endpoints
