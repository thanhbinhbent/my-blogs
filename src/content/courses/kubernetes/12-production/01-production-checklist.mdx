This lesson covers production readiness:

- Resource requests/limits on every container
- Liveness and readiness probes configured
- PodDisruptionBudget (PDB) for graceful node drains
- Anti-affinity rules to spread replicas across nodes/zones
- Horizontal Pod Autoscaler configured
- Proper RBAC with least-privilege service accounts
- Image pull policy and private registry setup
- Resource quotas and LimitRanges per namespace
- Network policies (default deny)
- Secrets management (not plain YAML)
